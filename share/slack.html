Baseline Fixer
Web app + CLI · woff2 · otf · ttf · woff

Text that sits in the middle.
On every system.

Most fonts put button labels slightly too high or too low, and by a different amount on macOS, Windows and Android. Baseline Fixer rewrites the font's vertical metrics once, in the file, so plain CSS centering just works everywhere.

The problem

One font, three stories about its height.

Browsers don't center glyphs. They center the font's content area, the space between its declared ascender and descender. A font stores those values three times, and each system reads a different set. When the sets disagree, the same label lands in a different spot on each OS, and a padding hack that fixes one breaks another.

Offset per system

(ascent − |descent| − capHeight) / 2

Positive means the text sits low. Zero only when the space above the capitals equals the space below the baseline. Independent of line-height.

The fix

Four changes to the font. Nothing else.

01

Measure

Reads the real cap height and x-height from the H and x outlines, plus the tallest and deepest glyphs.

02

Balance

Keeps today's macOS line height and splits it so the space above the caps equals the space below the baseline.

03

Unify

Writes identical values to hhea and OS/2 typo, zeroes line gaps and turns on USE_TYPO_METRICS.

04

Protect

Sizes the Windows win metrics to cover every glyph, so accents never clip. Variable fonts measured at every axis corner.

Rewritten

  • hhea ascender, descender and line gap
  • OS/2 typo and win metrics
  • USE_TYPO_METRICS flag (OS/2 raised to v4 if older)
  • MVAR line-metric deltas in variable fonts

Kept as is

  • Glyph outlines, widths and spacing
  • Kerning, ligatures and every OpenType feature
  • Variable axes and named instances
  • Names, copyright, license and version

How to use it

Drop fonts in. Get centered fonts out.

Web app

  1. 1Drop one or many fonts. Any of woff2, woff, otf, ttf, static or variable.
  2. 2Read the report. Offset per system before and after, simulated and live buttons, every changed metric.
  3. 3Fine-tune by eye if exact center looks a touch low. Nudge, preview, apply.
  4. 4Download .woff2 for web, .otf/.ttf for desktop, or all as a .zip.

CLI

# fix one font, format follows the extension
$ python fix_vertical_metrics.py in.ttf out.woff2

# center lowercase instead of capitals
$ python fix_vertical_metrics.py in.ttf out.otf --align x

# check offsets without writing anything
$ python fix_vertical_metrics.py in.ttf --report
  mac      before: 1.14px low @16px  after: centered
  windows  before: 1.14px low @16px  after: centered
